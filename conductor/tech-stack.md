# Tech Stack

## Core Services
- **[Retell AI](https://www.retellai.com/):** Conversational Voice AI platform for low-latency voice interactions.
- **[n8n](https://n8n.io/):** Workflow automation tool used as the central logic and integration engine.

## Infrastructure & Tools
- **Docker:** For containerized deployment of n8n.
- **Airtable:** Primary database for CRM, Lead Capture, and Support Tickets.
- **Cal.com:** Real-time appointment scheduling and availability management.
- **Twilio:** For sending automated SMS follow-ups.
- **Python:** For custom data processing scripts and analysis.
- **JSON:** For structured data transfer between Retell and n8n.

## AI Models
- **LLM:** Retell AI's built-in models or external integrations (e.g., OpenAI GPT-4o for tool calling and GPT-4o-mini for post-call processing).
- **TTS/STT:** Retell AI's optimized voice engines.
